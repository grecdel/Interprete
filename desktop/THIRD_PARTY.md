# Composants de la distribution

Interprete embarque Electron/Chromium et un service Python figé par PyInstaller.
Les fichiers de licence Electron et Chromium sont fournis avec le runtime
(LICENSE.electron.txt et LICENSES.chromium.html dans la distribution).

- Electron : https://github.com/electron/electron/blob/main/LICENSE
- Python : https://docs.python.org/3/license.html
- PyInstaller : https://pyinstaller.org/en/stable/license.html

Ces licences concernent leurs composants respectifs ; elles ne constituent pas
une attribution de licence au code d’Interprete.
