# Sécurité

Les fichiers APK/AppImage officiels sont distribués dans les versions GitHub de ce dépôt. Ne jamais publier une clé API, un fichier `.env`, le dossier `.android-signing`, un mot de passe ou un dossier d’enquête privé.

Pour signaler une vulnérabilité, utiliser **Security → Advisories → Report a vulnerability** si le signalement privé est activé sur GitHub. Sinon, ouvrir une issue demandant un canal privé, sans joindre d’exploit, de secret ou de données d’enquête. Ne pas publier de fichiers confidentiels dans une issue publique.

Le serveur de développement est réservé à la boucle locale. Les documents et réponses des fournisseurs sont des données non fiables. Les conclusions journalistiques nécessitent un contrôle humain.
