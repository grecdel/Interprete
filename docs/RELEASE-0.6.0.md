# Interprète 0.6.0 — sphère et particules

Nouveau logo sombre et sphère lumineuse avec particules orbitales. Quatre matières suivent le thème : eau, électricité violette, données numériques et fumée. Les animations respectent la préférence système de réduction des mouvements.

Au premier lancement, Interprète se présente et propose un thème. Un clic sur la boule propose Record, une requête textuelle ou le panneau latéral. La même boule reste animée au centre de l’en-tête du panneau. Les réglages restent accessibles quand leur volet est ouvert.

## Installation

- Android 8+ : installer `Interprete-0.6.0-android.apk`. Cette mise à jour conserve le certificat de signature des versions précédentes. La permission de superposition reste nécessaire pour afficher la bulle hors de l’application.
- Linux x86_64 : rendre `Interprete-0.6.0-linux-x86_64.AppImage` exécutable, puis le lancer. Une archive portable `.tar.gz` est également fournie.
- Les sommes SHA-256 et les informations de signature Android accompagnent les fichiers.

Prototype : les conclusions et les sources doivent être contrôlées avant un usage journalistique. Le micro et les recherches distantes nécessitent les permissions, la configuration et le réseau adaptés.
